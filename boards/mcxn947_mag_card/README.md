# Oresat MCXN Mag Card

This repository contains the board files for the Oresat MCXN947 mag card.

It currently enables flexcomm4 UART for the console, I2C0 with ..., ADCs with ..., PWMs with ...,
DAC0 to mag torquers, and CAN. GPIOs are used for the heartbeat LED, ...

Follow the [README installation instructions](https://github.com/plskeggs/oresat-zephyr-common) for installation.
